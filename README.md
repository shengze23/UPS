# File: OpenUPS_Clone
This is a read-only OpenUPS status monitor for Windows 11. It displays voltage, current, cell voltage, temperature, output power, battery capacity, and estimated runtime. It does not change any UPS settings.

## How to use

1. Download and extract the entire ZIP file.
2. Connect the OpenUPS USB cable directly to Windows 11.
4. Double-click `RUN_FROM_SOURCE_WIN11.bat`.
5. The first launch installs the required packages automatically. Wait for the installation to finish.
6. When connected successfully, the window will show `OpenUPS Connected v1.9` and live UPS information.
